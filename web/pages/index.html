The game needs a browser build made from your disc. Build it with scripts/build_web.ps1 dmc, then select ps2web.html, ps2web.js, ps2web.wasm and ps2web.data. Game code and game data are supplied locally.

Use a current desktop Chrome or Edge. WebGPU is recommended. Saves belong to this site’s browser storage; export memory-card backups in the player’s settings. Localhost saves are separate.
